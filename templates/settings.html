Database Troubleshooting & Workbench Instructions
Running database.sql in MySQL Workbench
  1. Open MySQL Workbench and connect to your local MySQL connection.
  2. Press Ctrl + Shift + O (or File → Open SQL Script...).
  3. Choose database.sql from the project folder.
  4. Click the Lightning Bolt icon (Execute) to execute the whole script.
  5. Refresh the schemas list on the left side to see elearning_db.
Setting your .env Credentials
  1. Copy .env.example to .env in the project root directory.
  2. Set DB_PASSWORD=your_actual_mysql_password (your local root password).
  3. Ensure DB_USER=root and DB_NAME=elearning_db.
  4. Save the .env file and restart the Flask server.
